# 0003. cualign 랜딩은 영어로 쓰고 한국어 전용 사실은 FAQ 한 줄과 문서에만 둔다

- 날짜: 2026-09-28
- 상태: 유효
- 근거 커밋: `fe4ccbd`, `e2126eb`

## 배경

cuAlign 프로토타입의 인터페이스, 처방, 에이전트 응답은 한국어만 지원한다. 영어 랜딩이 영어 처방 예시를 보여 주면 방문자가 영어로 쓸 수 있다고 오해할 수 있었다.

## 결정

랜딩 화면(히어로, 대화 데모, 도구 이름, How it works)의 문구와 예시 처방은 영어로 둔다. 한국어 전용이라는 사실은 FAQ "What do I need to run it?" 답 끝의 "The current prototype interface is in Korean." 한 줄과 `apps/cualign/docs/`의 문서(overview, quickstart, planning, limits)에만 적는다.

## 대안

- **랜딩 전체에 한국어 전용임을 드러내는 방식(`fe4ccbd`)**: 처방과 에이전트 응답을 한국어 원문에 영어 번역을 붙여 보여 주고, Current scope와 언어 FAQ 문항, 실행 버튼 옆에 한국어 전용 고지를 두고, 한글 글꼴 Pretendard를 불러왔다. 약 3분 뒤 `e2126eb`에서 이 변경을 랜딩에서 되돌렸다. 되돌린 이유는 커밋 메시지에 적혀 있지 않다.

## 결과

- 랜딩에는 한글이 없으므로 한글 글꼴을 불러오지 않는다.
- 한국어 전용 고지를 랜딩의 다른 곳(히어로, 실행 버튼 옆)에 다시 넣으려면 이 결정을 바꾸는 것이다.
- 에이전트용 문서와 `llms-full.txt`에는 한국어 전용 설명과 예시 처방의 영어 풀이가 남아 있어, 에이전트는 이 사실을 문서에서 얻는다.
