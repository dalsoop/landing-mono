# cualign

cuAlign을 소개하는 정적 랜딩 페이지입니다. 빌드 단계 없이 이 폴더의 파일(`index.html`, `styles.css`, `404.html`, `assets/`)을 그대로 서빙하고, <https://cualign.external.kr> 에서 열립니다.

내용은 cuAlign 저장소(<https://github.com/dalsoop/nvidia-hackaton-2026-one>)의 `apps/cualign-prototype` README, `docs/OVERVIEW.md`, `docs/NVIDIA_STACK.md`에 적힌 사실만 옮깁니다. 그 문서의 범위나 한계가 바뀌면 이 페이지도 함께 고칩니다. 화면 이미지(`assets/screen-*.jpg`)는 `/ui/v2/`의 샘플 케이스를 찍은 것입니다.
