Rules

Geometry checks

Plans are checked for space shortage, collisions, movement per aligner and stage count. A benchmark runs those checks on five synthetic presets.

Agent

19 scripted scenarios

They cover revisions, plans that honestly fail, unsupported requests, and diagnosis questions the agent hands back to the dentist.

Clinical

One dentist, 12 cases

A dentist judged space and approach for 12 sample scans by eye. We treat it as a qualitative reference and report no score.

The automated tests (uv run pytest) and a rule-based plan (cualign plan) run offline. The verification record in the source repository lists what passed and what hasn't been checked. Clinical validity is not evaluated.

Input

Segmented upper-arch scan

One STL per tooth, numbered in the Universal system, plus an optional gum scan.

Output

ZIP of stage files

Per-tooth STL for every stage and, with a gum scan, a printable arch model per stage.

Not yet tested with specific intraoral scanners, CAD software or 3D printers. Automatic segmentation of one-piece scans is not supported.

What it handles today,
and what it doesn't yet.

  • Upper arch only. Translation, incisor rotation and vertical correction.
  • Not yet modelled. Rotation of canines and back teeth, torque, the lower arch, occlusion.
  • Computed checks. IPR adjusts space only in the calculation, and the collision check doesn't guarantee zero contact for every tooth pair.
  • Hosted or local. A hosted prototype is available on request. You can also run it on your own machine.
  • For review. Exports are not validated for manufacturing or wear.

Questions.

Is cuAlign a medical device?

No. It is a research prototype and must not be used for diagnosis or treatment decisions.

Which cases does it not support?

Lower arches, rotation of canines and back teeth, torque, occlusion, and one-piece scans that are not segmented per tooth.

What happens to scan data?

On the hosted prototype, scans and plans are stored on that server, behind access credentials. Run it locally and they stay on your machine. The agent conversation goes through the NVIDIA API either way, and there is no per-user isolation, so don't upload identifiable patient data.

How much does it cost?

Nothing. cuAlign is a research prototype and isn't sold.

What are the terms?

Use is covered by the End User License Agreement: research and demonstration only, no warranty. Sample scans are CC BY 4.0, and third-party components keep their own terms.

What do I need to run it?

Nothing, if you use the hosted prototype. We share its access details on request. To run it yourself you need Python 3.12 and uv. Plans compute without a key, and the conversation needs an NVIDIA API key. The Quickstart walks through it. The current prototype interface is in Korean.
